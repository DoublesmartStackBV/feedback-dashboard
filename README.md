# Feedbacktool Doublesmart: dashboard

Het interne dashboard van de feedbacktool. Het staat online via GitHub Pages:

```
https://doublesmartstackbv.github.io/feedback-dashboard/
```

## Toegang

Alleen met een account van Doublesmart. Zelf aanmelden kan niet. Na het inloggen
praat het dashboard met een functie in Supabase; die controleert bij elk verzoek
of je bent ingelogd en toegang hebt. Deze pagina bevat geen sleutels en geen gegevens.

## Beheer

Deze bestanden worden niet hier bewerkt. Ze worden gebouwd in de (privé)
projectrepo van Doublesmart en daarvandaan hierheen gekopieerd.
